Justice Society of Activism — Brand Package Installer

👋 Welcome! This page walks you through uploading every brand asset to your YouTube channel. No installation required — just follow the steps below. All files are in the brand/out/ folder.
0 / 9 steps

1. Channel Art

1

Upload Profile Picture

File: brand/out/avatar-800.png (800×800, 665KB)

→ Open YouTube Studio Branding page

Click Change under Picture, select the file, click Done → Publish

2

Upload Channel Banner

File: brand/out/banner-2560x1440.png (2560×1440, 4MB)

→ Open YouTube Studio Branding page

Click Change under Banner image, select the file. The wordmark and crest are in the safe area so they show on all devices.

2. Basic Info

3

Set Channel Name

Change from "Orlando C Johnson II" to Justice Society of Activism

→ Open YouTube Studio Basic info page

4

Set Handle

Should already be @JusticeSocietyofActivism — if not, change it

5

Paste Channel Description

Justice Society of Activism is an independent, member-funded reporting studio. We follow the paper trail — court filings, budget records, FOIA releases — and turn it into stories people can act on. No billionaire owners, no PR clients, no rage-bait. If it can't be sourced, we don't air it. New documentary every Thursday. Support the work: https://justicesociety.org/give Public records database: https://data.justicesociety.org Press inquiries: press@justicesociety.org

3. Video Watermark

6

Upload Watermark

File: brand/out/channel-watermark-150.png (150×150, 22KB)

→ Open YouTube Studio Branding page

Scroll to Video watermark, click Upload, select the file. Set display time to End of video or Custom: 0:15 to End. YouTube makes it automatically clickable.

4. Userscript (Optional but Recommended)

7

Install Tampermonkey

→ Download Tampermonkey for your browser

Works with Chrome, Firefox, Edge, Safari. Install the extension.

8

Install JSA Studio Script

⚡ Click to Install Script

Tampermonkey will open and ask you to confirm. Click Install.

9

Activate on Your Channel

→ Visit your channel

Click the Channel setup button (next to the red Studio button in the lower-right). Toggle "Apply brand to channel page" ON. Your channel is now decorated.
